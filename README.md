# YellowChain Protocol

YellowChain is an evidence-first sovereign economic intelligence fabric for the real economy.

It connects companies, products, services, opinions, evidence, governed AI assistance, N-BIL/G-BIL event provenance, public claim boundaries, and contribution-to-outcome logic.

## Status

Canonical protocol and MVP build-preparation phase.

Not production. Not a token launch. Not compliance certification.

## Core law

Claim ≠ Evidence ≠ Specification ≠ Code ≠ Deployment ≠ Production.

## Bulgaria MVP focus

Companies, products, services, opinions, provider dashboard, quote/request flows, correction/dispute routes, and bounded vertical AI assistants.
