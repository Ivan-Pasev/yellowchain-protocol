# Security Policy

## Status

YellowChain is in canonical protocol and MVP build-preparation phase. No production deployment is claimed.

## Report a vulnerability

Open a private/security channel with the maintainer before disclosing exploitable details publicly.

## Do not include

- secrets
- credentials
- private evidence files
- real partner data
- provider/customer data
- production infrastructure details

## Security law

Do not claim assurance beyond evidence.
