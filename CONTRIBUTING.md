# Contributing to YellowChain Protocol

YellowChain welcomes protocol, schema, documentation, issue-template, and validation contributions.

## Boundaries

Do not submit secrets, private partner evidence, real imported datasets, confidential contracts, provider/customer data, production configs, payment details, or unverifiable public claims.

## Core law

Claim ≠ Evidence ≠ Specification ≠ Code ≠ Deployment ≠ Production.

## Contribution checklist

- Use clear scope.
- Add or update schemas when object contracts change.
- Preserve claim/evidence separation.
- Mark assumptions and unresolved legal/compliance states.
- Use synthetic examples only.
